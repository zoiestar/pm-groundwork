# Project Schedule / Plan

**Filename slug:** `project-schedule`

## Questions

**Q1 — What scheduling approach?**
- Waterfall / sequential → linear phases with dependencies
- Agile / iterative → sprints with incremental delivery
- Hybrid → planned phases with agile execution
- Not decided → propose one based on the project type

**Q2 — Key milestones and target dates?** Freeform. Pre-fill from `PLAN.md` and MEMORY.md.

**Q3 — External dependencies or fixed dates?** Freeform.

**Q4 — What level of detail?**
- High-level milestones → major checkpoints and dates
- Phase-level plan → phases with activities and durations
- Detailed task plan → full breakdown with dependencies

## Output sections

Schedule Overview · Assumptions & Constraints · Milestones (table: Milestone, Target Date, Owner, Status, Dependencies) · Phase Breakdown (per phase: objectives, key activities, duration, deliverables, entry/exit criteria) · Dependencies (table: Dependency, Type, Impact, Owner) · Critical Path Summary · Resource Requirements · Schedule Risks · Change Management
