# Work Breakdown Structure (WBS)

**Filename slug:** `wbs`

## Questions

**Q1 — What level of detail?**
- High-level (2 levels) → major deliverables and key work packages
- Detailed (3-4 levels) → full decomposition to task level
- Start high, detail later → framework now, refine as planning progresses

**Q2 — What are the major deliverables or phases?** Freeform. Pre-fill from `PLAN.md` phases.

**Q3 — How should work be organized?**
- By deliverable → group by what's being produced
- By phase → group by timeline
- By team / function → group by who does the work
- Hybrid → combination

## Output sections

WBS Dictionary Header (project, version, date) · WBS Hierarchy (indented outline with IDs: 1.0, 1.1, 1.1.1) · WBS Dictionary (table: WBS ID, Work Package, Description, Owner, Estimated Effort, Dependencies) · Assumptions · Exclusions

## Pre-fill

If `PLAN.md` exists, map its phases and deliverable items into the WBS structure.
