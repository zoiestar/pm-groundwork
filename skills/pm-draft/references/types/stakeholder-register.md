# Stakeholder Register

**Filename slug:** `stakeholder-register`

Pre-fill from the MEMORY.md stakeholders table before asking anything.

## Questions

**Q1 — "I found these stakeholders: [list with roles]. Anyone to add, remove, or update?"** Freeform, or "this covers it".

**Q2 — How detailed should the engagement strategy be?**
- Basic → name, role, influence level, key interests
- Detailed → adds communication preferences, engagement approach, risks
- Comprehensive → full RACI plus influence/interest matrix plus engagement plan

**Q3 — Any stakeholder relationships or dynamics to be aware of?** Freeform, or "nothing specific".

## Output sections

Purpose · Stakeholder Register (table: Name, Title/Role, Organization, Contact, Interest in Project, Influence H/M/L, Support Level — Champion/Supporter/Neutral/Resistant, Key Expectations, Communication Preference, Engagement Strategy) · Influence/Interest Matrix (2x2: Monitor, Keep Informed, Keep Satisfied, Manage Closely) · Engagement Plan for high-influence stakeholders · RACI Matrix (comprehensive level only) · Review & Update Schedule

## Sensitivity

This document records candid assessments of real people — support level, influence, dynamics. Say once, before writing, that this is usually an internal document and worth thinking about before it gets shared or committed to a repo others can read.
