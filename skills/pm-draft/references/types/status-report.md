# Project Status Report

**Filename slug:** `status-report`

Pre-fill heavily. This type should ask the fewest questions, because nearly everything is already in the workspace.

## Questions

**Q1 — Reporting period?**
- This week → last 7 days
- This sprint → current iteration
- This month
- Custom period → specify dates

**Q2 — Who receives this?** Pre-fill from MEMORY.md stakeholders, or the communication plan in `docs/` if one exists.

**Q3 — Specific wins or concerns to highlight?** Freeform, or "just the facts".

**Q4 — Overall project health?**
- Green → on track, no significant risks
- Yellow → at risk, mitigation in progress
- Red → off track, significant blockers or missed milestones

## Output sections

Header (project, period, author, date, status: Green/Yellow/Red) · Executive Summary (2-3 sentences) · Progress Summary (table: Phase, Status, % Complete, Notes) · Accomplishments This Period · Risks & Issues (table: Item, Type, Impact, Owner, Status, Mitigation) · Decisions Made This Period · Upcoming Work · Resource & Budget Status · Action Items (table: Action, Owner, Due Date)

## Pre-fill

Progress from `PLAN.md` phases and tick counts. Accomplishments from recent `memory/` daily logs. Risks from MEMORY.md. Decisions from DECISIONS.md entries dated in this period. Upcoming work from the next unchecked items in `PLAN.md`.
