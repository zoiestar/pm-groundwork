# User Stories / Journey Map

**Filename slug:** `user-stories` or `journey-map`

## Questions

**Q1 — What user type or persona is this for?** Freeform.

**Q2 — What scenario or workflow are you mapping?** Freeform.

**Q3 — What format?**
- User stories (Agile) → as a [user], I want [goal], so that [benefit]
- Customer journey map → end-to-end experience with touchpoints and emotions
- Both → stories organized within a journey framework

**Q4 — What's the scope?**
- Single feature → one interaction or workflow
- End-to-end experience → full lifecycle or key workflow
- Multiple personas → different user types through the same experience

**Q5 — Existing user research to incorporate?**
- Yes, let me share key findings → freeform follow-up
- No research yet → base it on what we have
- Research exists, I'll add it later → leave marked placeholders

## Output sections

**User stories:** Persona Summary · Epic Overview · User Stories grouped by theme (each with ID, story, acceptance criteria, priority) · Dependencies Between Stories · Open Questions

**Journey map:** Persona Summary · Journey Overview · Journey Phases (table: Phase, User Action, Touchpoint, Emotion, Pain Points, Opportunities) · Key Insights · Recommended Improvements · Metrics to Track
